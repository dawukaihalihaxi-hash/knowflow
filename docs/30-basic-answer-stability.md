# 基本问答稳定性修复与验收（2026-11-12）

## 已确认范围

用户要求修复学生票、儿童票、违禁品等基本问答反复失败，并授权真实模型回归。保留现有模型、2000 tokens输出上限、既有知识索引与向量、权限和配额。不开新功能，不改变前台报错分类。不为通过测试放松事实和引用校验。

## 已复现的问题

旧实现8题两轮16次真实调用，4次失败：两次学生票引文改写、删节或以省略号拼接；两次儿童票改写问法生成本次不存在的S13引用。均finish_reason=stop，非2000上限截断。此前多段引文修复仅覆盖空行分段的一种情况，不能解决这些失败。原始失败记录保存在本机私有诊断目录，不公开到GitHub。

## 实现

- `src/evidence_protocol.py`：为本次授权证据的原文段落分配临时编号；短标题与相邻段合并，保留原文及版本。模型只选择编号，服务端还原原文，再走原有严格校验；未知编号、无引用、截断、非法JSON仍拒绝。不作模糊匹配，不添加模型自动重试。
- `prompts/evidence-protocol-v1.txt`：通用引用协议及条件/版本检查，独立于助手业务Prompt；普通用户不能覆盖。
- `config/model-options.json`：维护端声明模型支持段落协议及严格JSON Schema。未声明的模型保留旧协议，不擅自替换模型。
- `src/answer_service.py`：严格输出结构、请求级引用解析，保留私有校验原因。
- `src/web_app.py`：线上启用已声明协议；失败时保留有界私有诊断记录（默认20份），即使完整调试关闭，仍可由管理员排查；普通访客不可读取原始记录。前台错误文案未扩展。

## 尚存边界

- 本机至知识数据库出现少量响应传输中断，未归为引用修复成功；不擅自改用未授权数据或伪造答案。线上页面结果单独记录。
- 学生票使用次数虽已给出每学年四次，现有业务Prompt仍较保守，可能附带2023/2025版本适用性提示；这不是引用失败，但表达仍可简化，本轮未通过强制删掉风险提示来假装问题解决。
- 平台引用协议文件采用不可变版本名；后续内容变更应使用新版本路径及代码引用，避免持久工作空间恢复旧版同名Prompt。
- `evals/regressions/basic-answer-stability.json`保存本轮固定问题及人工审阅标准。真实模型调用需明确执行，离线测试不会调用模型或重新向量化。
