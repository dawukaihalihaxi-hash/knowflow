# Contributor rules

Keep business branding, models and prompts configurable. Never commit credentials, uploaded private documents, runtime data, generated logs or local screenshots. APP_PUBLIC_TRIAL=1 enables quota-limited anonymous assistants backed by private Supabase storage. Anonymous visitors cannot modify the sample or other visitors’ assistants; only the administrator can manage the sample. Never bypass server ownership checks or quota reservations. Tests must mock paid services. Public corpus provenance is recorded in knowledge/railway/manifest.json.
